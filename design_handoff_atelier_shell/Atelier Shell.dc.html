Three shells for running many agents at once

Same content as today, three different answers to the same four problems: sessions you can scan, one place for status instead of five, failures you cannot miss, and spend you can see. MCP is demoted everywhere — it only speaks up when it is broken. Styling follows the Datadog dark UI system: violet accents, Roboto Mono for status and figures.

1a Board The session list becomes the home screen. No transcript until you pick one.

Parallel work is the default, so the shell is a status board, not a chat window with a list bolted to it. Everything that used to live in three separate chrome zones — RUNNING, profile, model, MCP counts, version — is one top line. Anything needing a human is pulled into a single strip you have to read.
